# LimeCore

Custom Paper SMP core.

## Current
- Paper 1.21.8 / Java 21
- `/ap` in-game admin GUI for OPs (and limecore.admin)
- Random Event engine
- Blood Moon, Mob Invasion and Chaos events
- Built as the base for custom items, mobs, mechanics and future content

## Build
```bash
mvn clean package
```
The JAR will be created at `target/LimeCore-0.1.0.jar`.
